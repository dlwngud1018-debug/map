# 진솔공인중개사사무소 · 매물 지도

노션 매물장을 고치면 지도에 자동 반영되는 웹페이지입니다.
공개용(손님)과 내부용(연락처 표시) 두 가지로 동작합니다.

카카오 개발자 등록은 필요 없습니다. 준비물은 노션 토큰 하나뿐입니다.

---

## 1단계 · 노션 토큰 발급 (5분)

1. https://www.notion.so/my-integrations 접속
2. `새 API 통합` 클릭 → 이름 `매물지도` → 제출
3. 화면에 나오는 `내부 통합 시크릿` 복사 (ntn_ 으로 시작)
4. **필수** — 노션에서 "부동산 매물 관리" DB 페이지를 열고
   우측 상단 `...` → `연결` → 방금 만든 `매물지도` 선택
   (이 단계를 빠뜨리면 권한이 없어 조회가 안 됩니다)

---

## 2단계 · Vercel 배포 (10분)

1. https://vercel.com 접속 → `Sign Up` (GitHub 계정 권장)
2. 이 폴더를 GitHub 저장소에 올린 뒤
   Vercel에서 `Add New` → `Project` → 저장소 선택
3. **Environment Variables** 에 아래 3개 입력

| 이름 | 값 |
|---|---|
| `NOTION_TOKEN` | 1단계에서 복사한 ntn_... |
| `NOTION_DB_ID` | 2e72d7583102805ebe22ce0f246cb378 |
| `ADMIN_KEY` | 원하는 암호 (예: jinsol2026) |

4. `Deploy` 클릭 → 1~2분 뒤 주소가 나옵니다

---

## 사용법

**공개용 (손님·홍보)**
```
https://내주소.vercel.app
```
연락처가 전혀 표시되지 않습니다. 서버 단계에서 아예 빼고 보내므로
브라우저 개발자도구로도 볼 수 없습니다. 링크를 자유롭게 공유하세요.

**내부용 (사무소)**
```
https://내주소.vercel.app?key=jinsol2026
```
임대인·임차인 연락처가 함께 표시됩니다. 외부 공유 금지.

## 매물장 작성 규칙

지도에 뜨려면 **좌표** 칸이 채워져야 합니다.
기존 매물은 전부 채워져 있습니다. 새 매물만 신경 쓰면 됩니다.

**새 매물 등록 시**

1. `주소` 칸에 지번 주소를 씁니다
   예: `경기도 김포시 사우동 980`
2. `좌표` 칸을 채웁니다
   - 카카오맵/네이버지도에서 해당 위치 우클릭 → 좌표 복사
   - 또는 Claude에게 "새 매물 좌표 채워줘" 라고 하면 대신 넣어줍니다
   - 형식: `37.620783,126.716256` (위도,경도 · 쉼표로 구분)

좌표가 비면 그 매물은 지도에 안 뜨고,
화면 좌측에 "좌표 없어 미표시 N건" 으로 알려줍니다.

**자동 반영되는 항목**
매물명, 주소, 거래 유형, 매물 종류, 매매가액, 보증금, 월세,
권리금, VAT, 면적, 층수, 매물 상태, 특이사항

매물 상태를 `계약 완료` 로 바꾸면 공개 지도에서 자동으로 사라집니다.
매물명에 `삭제요망` 이 들어간 행은 항상 제외됩니다.

## 주의사항

**표시·광고 규정**
공개 화면 하단에 「공인중개사법」 제18조의2 관련 문구가 자동 표시됩니다.
다만 법정 명시사항(총 층수·사용승인일·향·방/욕실 수·입주가능일·
주차대수·관리비)은 매물장에 채워두셔야 완전한 광고 요건을 갖춥니다.
현재 비어 있는 건이 많으니 순차적으로 채우시길 권합니다.

**실매물 유지**
공개 웹페이지도 인터넷 표시·광고에 해당할 수 있습니다.
거래 완료 매물은 즉시 `계약 완료` 로 바꿔 노출을 중단하세요.
